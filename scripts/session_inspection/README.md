# 完整检查：双击 BAT

**双击 `inspect_sessions.bat`**，原始数据在 `F:\` 就回车，共享目录没有就回车。
然后选择动捕帧率：240 FPS 填 `8`（默认），120 FPS 填 `4`。不用手动输命令。
请保留完整工具文件夹并预装 uv。运行会完整读取数据和解码视频，需要比以前更久；等待窗口显示结束即可。

检查内容：

- 每个 Segment 的六路头戴视频、头戴 IMU/MAG、左右腕视频和 IMU/MAG 是否齐全。
- 动捕目录是否唯一、是否有至少一种动捕数据格式及第三人称视频。不强制同时拥有全部导出格式。
- 视频能否完整解码且有画面帧；数据库能否读取、表和字段是否存在、是否有实际有效记录。
- TRC/CSV/XRS/BVH/C3D 是否有实际轨迹数据；支持的文本格式会核对列数、实际行数与表头，区分截断、空数据、部分缺点。
- 原有帧数关系、时间戳与丢帧分析仍保留。原始录制不要求提前存在发布清单；已下载副本可用 `--layout published` 额外要求清单和检查报告。

结束后自动打开汇总表。结果在 `_artifacts/session_inspection/<运行时间>/`：

- `report.html`：先看问题汇总，再点开每个 Session 的完整报告。
- `sessions.csv` / `issues.csv`：录制汇总 / 具体问题。
- `run.log` / `scan_errors.csv`：运行日志 / 扫描未完成的位置；各 Session 还有视频解码日志。

“文件检查通过”不等于时间戳、同步或动作质量通过，请同时看报告原有的帧数和时间戳部分。
发现问题只报告，不删除、不修补、不上传。正在录制、有数据库未合并日志、无法识别的格式都会明确提示，不会算作通过。
三项退出码：0 为文件检查通过，1 为有问题或扫描不完整，2 为参数或环境问题。
