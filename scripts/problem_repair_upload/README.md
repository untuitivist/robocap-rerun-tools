# 已知问题一键修复

1. 保留完整工具文件夹，使用已配置好数据集账号、uv、Git/Git LFS 的电脑。
2. 双击 **repair_problem_sessions.bat** 就开始，**不需要 Markdown，不需要输入路径，也不用回答问题**。
3. 等窗口结束，自动打开检查报告。报告和日志在工具根目录 `_artifacts/problem_repair_upload/<时间>/`。

工具内置截至 2026-10-22 已核对的 **1,449 个 Session、1,552 项问题**。自动搜索本机所有盘和当前账号能访问的网络共享；有 F 盘时会自动搜索，不需要知道共享地址。

找到匹配的有效原文件就直接补传，校验远端 SHA-256 后才记为解决。远端已正常的文件不覆盖，原文件和其他元数据保留；此前已解决的条目仍会读回验证。

缺原件、文件损坏、多个有效副本冲突、配对/时钟和量程问题都会写进报告。查看 `results.csv` 逐项处理，`files.csv` 看文件明细，`network_discovery.csv` 看共享访问结果。找不到原件不等于远端仍坏，也不等于无法恢复。

共享未开启、账号无权限时无法读取对方 F 盘，直接在有 F 盘的现场电脑双击运行即可。工具不修改共享权限、不删除原件、不猜测补帧、不自动交换 Session。压缩包需要先由现场人员解压。

维护人员可选参数：`--root "F:\." --apply` 指定搜索盘；`--scan-only` 仅搜索；`--sources-index "上次结果目录\sources.json"` 复用目录索引。`--report` 仅供维护人员导入新的问题清单，普通使用无需提供。命令行方式必须显式加 `--apply` 才上传。
