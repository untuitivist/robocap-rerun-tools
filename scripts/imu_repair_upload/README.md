# 右手 IMU 检查

用于确认：右手有没有加速度（ACC）和角速度（GYRO）数据，问题集中在哪个设备、哪天、哪些人。只检查，不修补、不上传。

1. **双击 `inspect_right_imu.bat`**。请保留完整仓库，电脑需装好 uv。
2. 原始数据在 `F:\` 就直接回车，否则输入实际目录；共享目录没有就回车。路径不用加引号。
3. 等检查结束，统计表会自动打开。窗口保留，不会闪退。

结果在仓库的 `_artifacts/imu_repair_upload/<运行时间>/`：

- `report.html`：中文统计表，可以搜索设备、日期、人员、动作或 Session。
- `devices.csv`、`dates.csv`、`participants.csv`：分别按设备、日期、人员汇总。
- `files.csv`：每个录制片段的检查结果和文件位置。
- `scan_errors.csv`、`run.log`：读取失败或检查未完成时，把这些文件交给负责人。

检查只针对 `robowrist_*_right` 右腕设备，不把头戴设备的右侧 IMU 算进去。区分“两路有记录、两路全空、只缺一路、缺文件、零字节、损坏、缺表/字段、LFS 占位”。
正在录制或存在未合并数据库日志时会提示停止录制后重查。

每个目录、片段、设备分别计数，不同位置的副本也分别计数；日期按北京时间。
两路有记录不等于采样率、同步和数值都合格。空库不能靠重传同一文件修好。
工具不展开 ZIP/RAR，也跳过生成报告、上传暂存和标定目录。

维护人员可通过 BAT 的 `--help` 查看参数；退出码 0 表示扫描完成（不代表全部数据有效），1 表示扫描不完整，2 表示参数有误。
